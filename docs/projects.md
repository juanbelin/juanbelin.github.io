# Projects imported from GitHub

The four requested README files are stored verbatim in `docs/github-readmes/`.
The project articles in `src/content/projects/` contain their README text, with
relative image and link URLs resolved to their original public repositories.
One incomplete HTML image tag in the Hit-The-Dns README has been closed so it
renders correctly. No instructions or source code were added to the README text.

`npm run import:projects` rebuilds the article Markdown from those saved README
files. The import date is internal metadata for sorting, not a claimed project
creation date, and is not displayed on the project article pages.
